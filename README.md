# Flamer

A Flamer é um sistema inteligente que utiliza inteligência artificial para monitorar, analisar e prever padrões de queimadas em tempo real. A proposta do projeto é oferecer uma solução preventiva para fazendeiros, identificando possíveis riscos de incêndios próximos às suas propriedades antes que eles se agravem. A partir da análise de dados ambientais, históricos e comportamentais, a plataforma consegue emitir alertas antecipados, permitindo uma resposta rápida e estratégica, reduzindo prejuízos e impactos ambientais.

Cada usuário possui uma conta personalizada com acesso a um dashboard exclusivo da sua fazenda, onde pode acompanhar informações relevantes sobre sua área e os riscos ao redor. Além disso, a Flamer conta com uma visualização global interativa na página inicial, exibindo ocorrências de queimadas em diferentes regiões do mundo. Essa combinação de monitoramento local e visão global torna a plataforma uma ferramenta poderosa para gestão de riscos e tomada de decisão no agronegócio.
